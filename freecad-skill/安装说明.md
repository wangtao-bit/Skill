# 本地 FreeCAD 画图技能

本包包含 `local-freecad-design/SKILL.md` 和 `references/f330-case.md`。两者分别是通用建模流程和 F330 案例复盘。它们可直接阅读，不依赖原电脑的工作目录。案例末尾的旧工程路径仅用于追溯。

## 安装到另一台电脑

1. 解压 ZIP，进入 `freecad-skill` 文件夹。
2. **Linux / macOS：** 在该文件夹打开终端，执行 `sh install.sh`。脚本安装到当前用户的 `~/.agents/skills/local-freecad-design/`，不用 `sudo`。同名目录已经存在时会停止，方便你保留自己的修改。
3. **Windows 原生环境：** 将整个 `local-freecad-design` 文件夹放到 `%USERPROFILE%\.agents\skills\` 下；父目录不存在时先创建。若在 WSL 中运行 Codex，请在对应的 WSL 环境中按 Linux 方法安装。
4. 新开一个 Codex 对话，输入：`用 $local-freecad-design，根据我的 STEP 模型设计一个可打印的支架。` 如果找不到技能，先检查 `SKILL.md` 是否直接位于 `skills/local-freecad-design/` 下，而非多套了一层 `freecad-skill/`。

该包迁移的是技能说明，不含 FreeCAD 软件、STEP 查看器或 F330 原始模型。实际画图时，请准备本机可运行的 FreeCAD 和本次任务的输入模型。
